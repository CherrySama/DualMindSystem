2026-10-04。按推开接触、按压下降超时、跨物体接近与避障的顺序推进，本次先完成推开接触的只读核查。运行代码尚未修改；没有新增任务回合、执行动作或调用 JEV。

## 确认的事实

核查对象为 `runs/local_intent_validation_20261003/push_aside_two_005/episode_001`。原回合源码指纹为 `012126b4...`；第一轮后的当前指纹为 `6893f4b1...`。本次核对的 36 份场景、配置、仿真与视觉源码文件和该回合一致，当前运行指纹也与第一轮完成时一致。

### 接触动作沿着侧面横移，没有持续接近侧面

JEV 选中了 `approach_edge_1`，对应观测外框的 −Y 侧。首次进入接触阶段的状态为 1025：

| 项目 | 基坐标系数值 |
| --- | --- |
| 物体中心 XY | `(0.350066, 0.179954)` m |
| 所选侧面 Y | `0.164996` m |
| TCP XY | `(0.344040, 0.125189)` m |
| 留存预接触目标 XY | `(0.350066, 0.134996)` m |

因此，首次状态中从所选侧面外侧接近物体的法向是 +Y；+X 是沿侧面的切向。

接触阶段共执行 20 次动作：17 次 FORWARD（+X）、2 次 BACKWARD（−X）、1 次 LEFT（+Y）。19 次原子动作完成，最后一次 +X 动作超时。全部保存的接触阶段状态都报告工具接触 CLEAR。

这些动作不是被 Runtime 的 XY 进展检查反复拒绝。当前接触意图是 `phase_contract`，没有局部 XY 点误差，因而不进入该进展审查。Runtime 执行了动作，但物理接触尚未建立，阶段不通过有依据。

### 动作输入缺少工具接触面的几何关系

首次接触动作输入保留了所选预接触点，但接触意图的数据为：

```json
{
  "choice_id": "establish_push_contact",
  "metric_kind": "phase_contract",
  "target_robot_base_m": null,
  "correction_robot_base_m": null,
  "distance_m": null,
  "action_evaluations": []
}
```

`runtime/local_intent.py` 只为 `tcp_xy`、`tcp_z` 意图计算修正；接触阶段生成的是 Boolean 契约意图。`policies/jev_context.py` 仅在存在修正时生成动作几何预测。两处代码共同解释上述空值。

不能直接把留存预接触点当作接触目标：它有意离开物体边界 30 mm。TCP 也不是夹爪的实际碰撞面。当前 RobotState 有 TCP 姿态和开度，但没有已标定工具形状；预接触验收检查的也是 TCP 到观测外框的距离。

### 实际工具形状支持上述判断，但不能只看整个夹爪外框

原场景中参与推动碰撞的是左右夹指网格；`press_tip_geom` 在推开场景关闭碰撞。不能把按压头作为这项任务的接触工具。

用保存的六关节角、左指开度和原模型做静态几何重建，按物体高度带裁切夹指凸包。首次接触状态的左指到所选侧面平面间距约 35.26 mm；第一次 +X 后约 35.24 mm；唯一一次 +Y 后降到约 26.74 mm。后续 +X 主要改变切向位置，并逐渐离开有限侧面的 X 范围。

整个夹爪的 Y 外框包含位于方块上方的宽部位；它离物体较近，不等于方块高度内的指尖已接近。接触表达至少需要法向间距、有限侧面的切向重叠和高度重叠，不能只提供 TCP 距离或整个工具的 XY 外框。

该重建没有恢复完整物理积分状态；右指开度按对称机构估计。首次重建 TCP 与日志位置相差约 0.071 mm。上述距离是静态侧面平面间距，不是原回合真实碰撞距离、接触力或可执行路径证明。

### 遮挡导致轮廓缩小，却仍被声明为完整可信几何

接触阶段后段，观测 Y 尺寸由约 29.91 mm 缩成 5.51 mm，最终中心 Y 也由约 0.17995 m 变为 0.19216 m。实体仍标为 CLEAR，轮廓和尺寸的置信度均为 1。

最终独立物理记录中，方块中心约为 `(0.350000, 0.180000, 0.014943)` m，左右夹指均未接触。结合末帧遮挡，这确认了最终视觉外框偏差，不能把观测中心变化解释为方块被推走。

`perception/fixed_rgbd.py::_build_entity` 直接把可见点 XY 的最小/最大值当作整个物体外框；至少四个有效点就报告 CLEAR，派生几何置信度固定为 1。它缓存 Z 尺寸，却未对 XY 的遮挡缩小作同等保护。简单补一条 +Y 提示无法解决后续参考轮廓失真。

隐藏记录只用于事后核查上述偏差，不会用于后续控制或构造接触目标。

## 结论

本回合同时存在动作选择未持续沿法向接近，以及接口没有工具—侧面连续几何的缺口。Runtime 没有把这段有效接触误判为失败。后段还存在视觉几何完整性问题。

这些证据足以确定应修的接口边界，但尚不能证明补齐表达后 JEV 一定会选对动作，也没有证明 +Y 动作能在原控制器下完成可靠推动。最后平移超时的原因仍未锁定，留到执行器核查。

## 待确认的最小实施方案

1. **补公开工具模型。** 使用机器人已知的标定形状、机械关系与机器人反馈计算夹指接触几何，标明来源；不读物体 MuJoCo 真值或隐藏验收。几何计算使用工具部件，输入只输出必要的接触摘要，不向 JEV 塞入全部网格顶点。当前状态未保存右指独立位置，实施时必须明确增加反馈或标注推导及误差，不能默认为测量。
2. **把选定侧面绑定到接触意图。** 保存主体、侧面端点与法向，计算法向间距、切向/高度重叠，并提供各允许动作的几何预期变化。单层和两层共用计算，JEV 继续选择动作。保持几何接近与实际接触验收分离，几何间距接近零不能代替接触证据。
3. **增加参考几何失效保护。** 对遮挡造成的明显轮廓缩小，不能继续把可见碎片当作完整物体边界；报告不完整/未知并使相关意图失效。保护先限定已有方块及可核对的历史形状一致性，不假装解决任意形状的姿态估计，也不直接以旧轮廓冒充新观测。
4. **分步验证。** 先验证工具标定、已选侧面和未知几何的契约，再用历史状态检查 +X 与 +Y 的几何变化及遮挡失效；通过后做短程物理接触探针，最后才做 JEV 推开回合。探针只验证几何/执行可行性，不作为规则策略任务成功或新的成功率。

预计涉及状态契约/构建、工具几何服务、局部意图、JEV 上下文和视觉完整性判断；先搭接口，再逐项填入，保留原场景、动作方向、步长、控制参数及最终成功门槛。新增数值必须说明标定依据与验证结果，不能靠调大容差绕过接触问题。
