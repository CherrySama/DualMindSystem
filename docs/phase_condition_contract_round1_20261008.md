# 第一轮：阶段条件与持续约束的共享证据契约

日期：2026-10-08。依据用户对架构评审第一步的明确批准实施，独立协作审查已完成。

## 结果与解决的问题

本轮完成 Runtime 到模型的共享状态表达基础。独立高层 LLM 尚未接入，两层模式仍由同一个 JEV 客户端先选局部意图、再选原子动作。

修改前有两处已确认的接口问题：点意图的动作输入删去了当前阶段完整条件；`maintain` 主要以名称传递，未统一表达是否有证据、是否适用以及能否核验。这样模型无法稳定区分“尚待建立的阶段目标”和“当前需要维持的条件”。本轮保留完整阶段条件，并用已有测量逐项解释持续约束，没有加入任务专用动作或新控制参数。

另一处修复是反馈来源绑定：核验结果现在绑定状态、动作 epoch、观测 ID 和完整不可变能力状态；生成反馈时同时核对能力实例、阶段、对象与目标。旧结果不能通过替换对象或能力实例套到新状态上。视觉与机器人测量时间也随反馈保存，未知来源或过期证据不能证明当前条件满足。

这是表达与绑定修复。既有阶段判定、稳定历史计算、动作拒绝规则、执行器、场景、配置和恢复机制没有修改。模型输入及提示规则发生了变化，在线动作选择是否改善尚未验证。

## 本轮职责边界

| 信息 | 本轮含义 |
| --- | --- |
| 阶段完成条件 | Runtime 已注册的完成目标；尚未满足不等于禁止建立它的动作。 |
| 持续约束反馈 | 在具名作用域内，依据当前已有证据报告状态；与阶段 passed/pending/failed 分开。 |
| 局部意图进展、动作预测 | 保持既有表达；预测不是实际观测，局部到点不是阶段完成。 |
| 阶段完成权限 | 仍由原 Runtime verifier 决定；新增约束报告不构成新动作门槛。 |
| 高层语义与策略 | 本轮未新增模型或接口，仍需后续受限入口设计与单独批准。 |

阶段通过与某个持续约束 violated 可以同时出现。两者报告不同问题，本轮保留这一诊断信息，不把它们合并成统一 allTrue 门槛。若后续要改变执行权限，需逐项论证约束含义与核验能力。

## 八类约束的语义映射

| maintain 名称 | 复用证据或条件 | 作用域 |
| --- | --- | --- |
| `subject_supported` | `subject_supported == true` | 当前阶段 |
| `candidate_grasp` | `grasp_candidate == true`；候选抓持不等于确认持有 | 当前阶段 |
| `subject_held` | `subject_held == true` | 当前阶段 |
| `subject_not_held` | `grasp_not_held == true`；未知不等于未持有 | 当前阶段 |
| `supported_push_contact` | `supported_push_contact == true` | 当前阶段 |
| `press_point_alignment` | 按压点 XY 误差不超过原具名容差 | 当前阶段 |
| `placement_relation_until_release` | 原放置水平关系条件 | 直到已核验且具有当前证据的释放事件 |
| `avoid_other_objects` | 缺乏覆盖完整含义的注册核验实现 | 明确报告 unsupported |

状态分为 satisfied、violated、unknown、unsupported、not_applicable。前两种需有当前支持证据；unknown 表示缺少可用证明；unsupported 表示完整核验能力尚不存在；not_applicable 仅表示已结束该约束作用域，不证明安全。开夹爪命令已发送或暂时丢失持有估计，均不能单独结束释放前的关系维持作用域。

支撑对象、候选抓持接触对象、按压点所属对象等引用不匹配时，约束反馈报告 unknown。该报告不重写原测量值和既有阶段判定。

## 证据时效与兼容边界

`PhaseConditionV1` 增加 `evidence_current`。保留原始 measured value；证据无效时 satisfied 为 None，避免把旧测量包装为当前证明。约束投影依据证据来源检查视觉、机器人反馈或二者的依赖；未知来源按未知处理。

视觉时效复用现有新鲜度与最大年龄配置，并要求捕获时间不早于最近动作结束。机器人反馈要求可用、测量时间与当前同步快照时间一致，且不早于最近动作结束。这依赖当前 StateBuilder 的同步仿真采集方式；尚未设计异步硬件的时钟同步与反馈有效窗口。

新反馈保存视觉捕获时间、机器人测量时间和时效状态。不同来源可以有不同时间，并不声称所有证据来自同一传感器或同一采样。旧档案新增字段使用兼容默认值；保存状态重放先重新核验，再投影新反馈。

抓持、接触和支撑仍含已有显式 MuJoCo 接触来源。本轮没有实现纯视觉估计或现实硬件替代。
