## 历史的含义

`phase.observation_basis` 标注当前测量依据；`phase.previous_observation_basis` 保存旧帧原始身份、作用域、时间和当时有效性。历史有效只说明在采集时有效，不能证明当前持有、接触或目标满足。

同名、同单位、同来源且前后有效的观察才支持比较。旧依据缺失、值为 None、有效性为假时不能认证变化。旧记录若仍能核对语义和动作边界，可保留原历史数值，但依据保持 None，不用当前依据补齐。command/configuration/history 来源不是物理效果实测；布尔关系 false → false 不表达连续距离改善。规则明确这些边界，程序没有自动计算或消费新的进展值。
