# 核心修复第一步：意图生命周期与实现证据交接

2026-10-05。按已确认的最小方案实施；用户进一步限定“重试的功能可以先不管，先把最核心的做好”。本轮处理阶段结束和跨阶段交接，未修改重试选择、重启规则、阶段拓扑、控制参数、验收阈值或隐藏验收。

## 修复的框架问题

原框架把三个不同事实混在了一条状态链里：JEV 曾选择一个局部目标、局部目标确实达到、Runtime 阶段契约通过。阶段通过可以合法结束尚未走完的路线，但不能把未实现的选择交给下一阶段充当已实现状态。

真实失败记录中，预接触契约在状态 1025 通过；JEV 所选 +X 点的误差仍为 74.808 mm，远大于 10 mm 容差。旧代码清空其活动执行，却保留所选 +X 侧并限制接触候选。这是已确认的交接语义缺口；并不证明 Runtime 的原阶段通过条件错误，也不证明它能解释十项任务的全部失败。

## 实际修改

1. **明确结束旧意图。** 阶段通过时，当前点条件在本次观测中已到达则记为 `completed`；未证实到达则记为 `superseded`。阶段失败记为 `cancelled`。正常阶段结束不消耗局部重规划预算。契约型或接触型意图必须由对应实际 Runtime 契约确认，几何距离为零不能替代实际接触。
2. **区分计划、实现证据与历史。** `retained_approach` 只保存本阶段选择；`handoff` 保存核验过的预接触 XY 状态；`last_termination` 保存原意图、原阶段、结束原因及状态/动作/观测绑定。结束事件只记录一次。
3. **交接重新核验。** 当前唯一需要跨阶段继承的接近侧面必须满足：绑定相同、视觉新鲜且不早于最近动作结束、完整侧面可观测、原参考未超过既有变化阈值、TCP 到本次观测重建的点仍在原容差内。没有证据时开放当前可观测候选，由 JEV 重新选择。
4. **保留合法流程。** XY 达到后调整高度，交接时再次核验 XY；高度调整没有破坏 XY 时保留所选侧面，发生偏离时撤销。每次更新都对原选择检查参考变化，不能靠多次小位移绕过阈值。此证据仅证明预接触 XY 条件，不证明实际接触或路径安全。
5. **保留停止原因。** 回合最终停止时取消仍活动的命令，记录 `run_stopped`；不会将执行超时伪装成阶段契约失败。没有正常结束通知的作用域变更取消旧绑定，不推断已完成。现有恢复流程未改。

修改限于五个生产文件：局部意图契约、局部意图运行层、共享循环、JEV 上下文、提示语。候选几何生成方式和动作选择者不变。共享循环先接收原 verifier 的真实结果，再通知意图层结束；意图层不重新裁决阶段。

## 正反例验证

修改前 161 项检查通过；修改后 177 项检查通过，新增 16 项核心检查。原先两项默认继承未到达侧面的测试已改为明确拒绝此继承，未删除这些检查。

- 合法阶段通过但所选点未到达：正常推进、明确结束、无交接、预算不增加。
- 所选点确实达到：只交接该侧面；真实接触条件仍 pending。
- 到达 XY 再调整高度：正常流程保留；XY 漂移则撤销。
- 视觉过期、部分可见、观测早于动作结束：撤销交接。
- 参考移动 12 mm：虽小于原 15 mm 参考阈值，但超过 10 mm 到达容差，不能用旧点证明实现；累计位移超过阈值也不能继承。
- 主体、能力实例、目标、源或目的绑定变更：不继承旧事实。
- pending 或错误契约反馈：不能结束当前意图；局部点到达也不能独立推进阶段。
- 抓取、按压的点完成及推动的路线结束共用同一生命周期；原共享循环的阶段推进、最终程序完成、回合停止均验证记录与绑定。

失败通知的一项检查使用显式构造的 failed 反馈，仅验证取消语义，未当作新的物理失败证据。共享循环检查使用真实 verifier 和转换；其中隔离的模拟执行测试使用测试客户端，不计入 JEV 完整任务评测。

本轮新增在线 JEV 请求 0、完整任务回合 0。原十二任务批次的 2/12 结果不变，不报告新的成功率。

## 尚未解决与下一步

这一步解决了“计划被当成实现事实”的接口问题。正例说明合法实现能交接，反例说明未实现选择不再污染后续阶段；它解释了这个边界为何可能在部分运行中潜伏、在另一些运行中暴露，但不能据此把所有历史成功或失败归到同一个原因。

第二个优先项尚未实施：局部距离进展、阶段全部完成条件、持续维护约束，需要在同一动作输入中表达各自含义和当前证据。下一步应先核对这些条件的适用边界及预测依据，再确认具体审查规则。接触高度不能因为一个下降失败就直接升级为所有动作的硬限制；抓持、接触等真实动态结果不能由命令预测冒充已成立。

动作选择问题、执行超时、持有证据失效和视觉/隐藏几何差异仍按原证据状态保留，未宣称解决。重试继续暂缓。
